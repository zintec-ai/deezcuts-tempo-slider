# Privacy policy: Deezcuts Tempo Slider

Effective date: 2026-11-25

The Deezcuts Tempo Slider browser extension collects no data.

## What the extension does

The extension adds a tempo fader to the players on `https://deezcuts.io`.
deezcuts.io plays tracks through SoundCloud embed widgets
(`https://w.soundcloud.com/player/*`). The extension changes the playback
speed of the audio in these widgets, in the browser. On other websites, the
extension does nothing.

## Data

- The extension does not collect, store, sell, or send personal data.
- The extension sends no network requests. It has no server and no
  analytics.
- The extension does not use cookies or browser storage. The tempo goes
  back to 0 % when the page loads again.
- On deezcuts.io, the extension reads the BPM (beats per minute) of the
  current track from the page. It uses this value only to show the BPM in
  the tempo control. The value does not leave the browser.
- The extension sends the tempo value from the deezcuts.io page to the
  SoundCloud widget frames in the same browser tab. The value does not
  leave the browser.

## Changes

If this policy changes, the new version will be in this file, with a new
effective date.
